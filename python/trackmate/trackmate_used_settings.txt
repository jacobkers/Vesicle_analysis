# Ring diffusion measurements: 
1. eventen detection
First, events are efficiently detected via a movie projection of standard deviation.


3. Ring diffusion:
Around each detected event, we define a number of ring areas from which to obtain summed intensity. Ring sizes are calculated such that each covers the same area as the central disk (with radius R0): we used the following edges for each ring (in pixels):  0, 5,12.07,15.73,18.66,21.18. Thus, ring 1 starts at radius 5 and stops at radius 12.07, and so on. The summed intnesity per ring shows the passing diffusion front. Then, the peak intnesity of each ring should be proportional to the D^2, where D is the diffusion coefficient.
